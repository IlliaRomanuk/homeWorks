# GreenShop — E-commerce Plant Store Landing Page

## Project Overview

GreenShop is a multi-section responsive front-end project for an online plant store, built as a large-scale HTML/CSS/JavaScript portfolio project.

The goal of this project was to recreate a production-style commercial storefront interface with emphasis on:

* Semantic HTML structure
* Advanced CSS layout architecture
* Interactive UI elements
* Responsive navigation
* Component-like section organization
* Realistic e-commerce design patterns

---

## Core Features

### Layout & Structure

* Semantic HTML5 architecture (`header`, `nav`, `main`, `aside`, `footer`)
* Modular page sectioning
* Multi-column product catalog
* Sidebar category filters
* Hero promotional section
* Blog section
* Newsletter subscription block
* Detailed footer with contact information and social links

### UI Components

* Multi-level dropdown navigation menu
* Burger menu for adaptive navigation
* Login / Register modal popup
* Product cards with:

  * Hover actions
  * Wishlist icon
  * Shopping cart icon
  * Product quick-view
  * Discount labels
* Custom checkbox filters
* Pagination controls
* Promotional banners
* Social authentication buttons
* Preloader animation before modal transition

### Styling System

* Separate CSS files:

  * `reset.css`
  * `normalize.css`
  * `style.css`
* Custom font integration:

  * Cera Pro family
* Organized asset directories:

  * Fonts
  * Images
  * Icons
* SVG logo integration
* Custom buttons
* Responsive design principles

### JavaScript Functionality

* Login button preloader animation
* Modal popup opening behavior
* Animated loading transitions
* Event listeners for UI state changes
